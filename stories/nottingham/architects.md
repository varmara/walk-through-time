# Architects named in OpenStreetMap

OpenStreetMap's `architect` tag gives a name as whoever mapped the building wrote it. Most are found on
Wikipedia by that name (an architect of that name, with an English article that mentions the city); these are
written differently, or need their article named. Architect: the name the map uses for them. Each checked by hand.
