# Architects

OpenStreetMap's `architect` tag, and Wikipedia's tables of an estate's houses, give an architect's name as
whoever wrote it. Most are found on Wikipedia by that name (an architect of that name, with an English article
that mentions the city). These rows are for the rest: a name written differently (Architect: the name the map
uses for them), an article the name alone does not find, or, where there is no article, another page about them
(Other source). Other sources are linked, never copied: none of them is openly licensed. Each row checked by hand.
