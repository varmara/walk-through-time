# Nottingham's stories

Stories, events, people and the layers' indexes are notes in `notes/`, one Markdown file each (an Obsidian vault);
beside them, tables of corrections and links. Threads, in the same indexes, follow stories, people, plaques and
buildings across places. How to write them: [CONTRIBUTING.md](../../CONTRIBUTING.md). Each data build checks every story
against its source and drops any that the source does not support; the build log lists them.
