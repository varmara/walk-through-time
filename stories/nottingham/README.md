# Nottingham's stories

One Markdown file per story layer (`NN-<id>.md`, in the order of the Layers sheet), and tables of corrections
and links. Topics (`topics/<id>.md`) gather stories, people, plaques and buildings from any layer on one subject. How to write them: [CONTRIBUTING.md](../../CONTRIBUTING.md). Each data build checks every story
against its source and drops any that the source does not support; the build log lists them.
